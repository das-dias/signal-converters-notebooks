    Practical Class 2 — Ideal ADC and DAC Modelling¶

    The models of an ideal ADC and DAC biased with a \(V_{ref}\) voltage and \(N\) bits of resolution are presented in this notebook. The conversion functions of both converters were created using the lambda programming style. The creator function for the ADC or DAC receives the two fundamental parameters defining these ideal electronic systems:

    • \(V_{ref}\) — the reference/biasing voltage of the converter
    • \(N_{bits}\) — the number of bits of the converter system (its digital resolution)

    The converter returns a function that, depending on its input, generates an output code or voltage for the ADC or DAC, respectively.

    import numpy as np
import matplotlib.pyplot as plt
from utils import dec2bin, ideal_dac, ideal_adc

    1. Digital-to-Analog Converter Modelling¶

    The ideal model for the transfer function of a DAC is implemented through a lambda programming style, as shown in (1). Other approaches, such as object-oriented programming with a DAC object, are also possible.

    \[V_{OUT}(D_{in}) = \text{base}_{10}\{D_{in}\} \cdot V_{LSB} \hspace{10pt} (1)\]

    where \(D_{in}\) is the input binary word, \(V_{LSB}\) is the least significant bit step voltage, and \(V_{OUT}\) is the output voltage of the DAC.

    vref = 5  # [V]
n_bits = 3

    Note: The step function representation of the DAC always uses a post-step (where="post"), meaning the output voltage is held constant until the next code transition.

    idac = ideal_dac(vref, n_bits)

x = np.arange(2**n_bits)
x_bin = np.array([dec2bin(i, n_bits) for i in x])
x_bin_str = ["".join([str(num) for num in xv]) for xv in x_bin]
y = idac(x_bin)

fig, ax = plt.subplots(2, 1, figsize=(4, 4))
ax[0].plot(x_bin_str, y, marker="o", mfc="None")
ax[0].set_xticklabels(x_bin_str, rotation=45)
ax[0].set_yticks(y)
ax[0].set_xlabel("Code")
ax[0].set_ylabel("Voltage (V)")
ax[0].set_title("Ideal DAC Transfer Function (Vout(Din))")
ax[0].grid(True)
ax[1].step(x_bin_str, y, marker="None", color="k", label="floor", where="post")
ax[1].set_xticklabels(x_bin_str, rotation=45)
ax[1].set_yticks(y)
ax[1].set_xlabel("Code")
ax[1].set_ylabel("Voltage (V)")
ax[1].grid(True)
fig.tight_layout()

    2. Analog-to-Digital Converter Modelling¶

    The ideal model for the transfer function of an ADC is implemented through a lambda programming style, as shown in (2). Other approaches, such as object-oriented programming, are also possible.

    \[D_{OUT}(V_{in}, f_{Round}) = \text{base}_2\{f_{Round}(V_{in}/V_{LSB})\} \hspace{10pt} (2)\]

    where \(V_{in}\) is the input voltage, \(V_{LSB}\) is the least significant bit step voltage, and \(D_{OUT}\) is the output digital code. \(f_{Round}\) is the rounding function implemented by the ADC, which can be:

    • round(.) — rounding to the nearest decimal
    • ceil(.) — rounding to the highest decimal
    • floor(.) — rounding to the lowest decimal

    The rounding function is parsed as an input to the ADC's transfer function for practical, low-code purposes.

    vref = 5  # [V]
n_bits = 3

    iadc = ideal_adc(vref, n_bits, np.round)
iadc_ceil = ideal_adc(vref, n_bits, np.ceil)
iadc_floor = ideal_adc(vref, n_bits, np.floor)

x = np.arange(0, vref, vref / 2**n_bits)

y = iadc(x)
y_str = ["".join([str(num) for num in yv]) for yv in y]

fig, ax = plt.subplots(2, 1, figsize=(4, 4))
ax[0].plot(x, y_str, marker="o", color="k", mfc="None")
ax[0].set_xticks(x)
ax[0].set_xticklabels(x, rotation=45)
ax[0].set_xlabel("Voltage (V)")
ax[0].set_ylabel("Code")

ax[1].step(x, y_str, marker="None", color="k", label="round", where="mid")

y = iadc_ceil(x)
y_str = ["".join([str(num) for num in yv]) for yv in y]
ax[1].step(x, y_str, marker="None", color="r", label="ceil", where="post")
ax[1].set_xticks(x)
ax[1].set_xticklabels(x, rotation=45)
ax[1].set_xlabel("Voltage (V)")
ax[1].set_ylabel("Code")

y = iadc_floor(x)
y_str = ["".join([str(num) for num in yv]) for yv in y]
ax[1].step(x, y_str, marker="None", color="b", label="floor", where="pre")
ax[1].set_xticks(x)
ax[1].set_xticklabels(x, rotation=45)
ax[1].set_xlabel("Voltage (V)")
ax[1].set_ylabel("Code")

ax[0].set_xlim([0, vref])
ax[1].set_xlim([0, vref])
fig.tight_layout()
ax[0].set_title("Dout(Vin)")
ax[0].grid(True)
ax[1].grid(True)
ax[1].legend()
