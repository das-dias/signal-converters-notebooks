    Resistive ADC Modelling and High-Level Simulation¶

    In this notebook, three architectures of ADC are modelled and a high level simulation is performed for each architecture. The covered ADC architectures are based in resistive arrays to enable the discretization of the reference voltage in each discrete voltage level, implementing the intrinsic DAC of the ADC. The generality of the existing ADC architectures are based on the use of a comparator to effectively digitize the input voltage. This notebook will have a special emphasis on the impact of the comparator offset in the ADC performance.

    Comparators: A brief introduction¶

    A comparator can be thought of a 1 bit ADC. If the input voltage of the ADC (at v+) is higher than the reference voltage of the comparator (at v-), the comparator will output a bit with a logical value of '1', whereas if the input voltage is lower than the reference voltage, the comparator will output a bit with a logical value of '0'.

    The higher the gain of the comparator, the faster is the transition between the two possible logical values at the output. Thus, comparators usually employ:

    • Positive feedback
    • Clock reset

    to ensure very high gains and fast transitions due to the instability of the comparator itself, using the clock reset to re-establish the correct operating point of the comparator.

    The main problem with Comparators¶

    The input of almost every comparator topology is based on the use of a differential pair. Due to mismatching, the employed transistors in the implementation of the input differential pair usually present different gate width and length dimensions, which ultimately affects the DC operating point of the comparator. This mismatching leads to a voltage offset between both inputs of the comparator. Of course that this offset is also present at the output of the circuit, once a comparator is basically an unstable amplifier with a "linear" response.

    Considering that the gate area mismatch is a random variable following a normal distribution, the voltage offset arising through the differential pair mismatch can be given by the standard error \(\sigma_{ofst} \approx V_{ofst}\):

    \[ \sigma_{ofst} = \sqrt{ \frac{A^2_{V_{TH}}}{W \cdot L} + \frac{A^2_{\beta}}{W \cdot L} \left( \frac{V_{GS} - V_{TH}}{2} \right)^2 } \]

    where \(A_{V_{TH}}\) and \(A_\beta\), with \(\beta = \mu \cdot C_{ox}\) are technology-specific parameters modelling how the threshold voltage \(V_{TH}\) and the channel mobility \(\mu \cdot C_{ox}\) vary with the gate area of the transistor.

    The offset will lead the comparator to decide its output logical value relative to a lower (negative offset) or higher (positive offset) input voltage than the reference voltage. This offset is usually modelled as a random variable following a normal distribution with a mean of zero and a standard deviation equal to the maximum offset amplitude (Vofst). The decisions happening "sooner" or "later", in relation to the voltage reference, will provoke missing-codes in the ADC's transfer function.

    Single Comparator Flash ADC¶

    The number of comparators in a flash ADC grows exponentially with the number of bits of the architecture, and thus it is not feasible to implement a flash ADC with a high number of bits. However, it is possible to implement a flash ADC with a single comparator. By using each individual voltage level from the resistive array, and using sequential control logic to implement a Binary Search Algorithm (Successive Approximations Algorithm), one can determine each bit of the ADC by determining if the input voltage is above or below that level. There is a quite evident tradeoff here - instead of using multiple comparators to obtain the result in a single conversion step, we are using a single comparator to obtain the result in multiple conversion steps.

    2-Step Flash ADC (without amplification = Sub-Ranging)¶

    The 2-step architecture of an ADC is based on the block diagram below. The 2-step architecture can be thought of a prelude for pipeline ADCs, in which the total ADC's resolution is spatially divided between two stages. The first stage will lay out the Most Significant Bits, and the residue of the first stage will be converted in the second stage, laying out the Least Significant Bits of the ADC. Of course that the range of the residue must be adjusted to the resolution of the second stage, and for that it is possible to either: 1) adjust the reference voltage of the second stage to a lower value (sub-ranging), 2) amplify the residue by a gain dependant on the resolution of the first stage so that it covers the full conversion range of the second stage (with amplification), 3) a combination of both (which we call a cheat in the academia).

    2-Step Sub-Ranging Flash ADC Operation¶

    At a first glance, the 2-Step Sub-Ranging Flash ADC can be quite tricky to understand, but it is actually much easier than it seems. As it is possible to observe in the general block description of this ADC architecture in the figure B) above, the reference voltage of the second stage DAC and ADC must be limited to VREF/2^N1, where VREF is the reference voltage of the first stage and N1 is the resolution of the first stage. To effectively obtain the least significant bits using the second stage, we must inject the residue voltage of the first stage as the input voltage of the second stage, which requires the performance of a subtraction of the input voltage and the resulting DAC voltage of the first stage.

    Well... this subtraction can become a big bottleneck of our design, once it requires the use of a subtraction circuit (either using an OPAMP for switched capacitors or continuous circuits), and as it turns out we can actually avoid it. At the expense of using a second stage that has an effective resolution of N2' = N1 + N2, where N2 is the desired resolution of our second stage, we can avoid using a subtraction circuit, by:

    • A) Using the first digital word to limit the range of comparison voltages in the second resistive string, defining an upper and lower limit
    • B) Limiting the amount of comparisons of the second stage to 2^N2 - 1, within the defined range of voltages
    • C) Obtaining the remaining Least Significant Bits from the same recursive algorithm within the defined range of comparison voltages of the second resistive DAC

    2-Step Sub-Ranging Flash ADC Monte Carlo Simulation¶

    The simulation below models the two-stage sub-ranging flash ADC architecture. In each Monte Carlo iteration:

    1. First stage: A resistive DAC with mismatch generates the coarse comparison voltages. The input is compared against these to produce the MSBs.
    2. Second stage: A finer resistive DAC (with total resolution N1 + N2) provides the fine comparison voltages. The first-stage digital word selects the appropriate sub-range of comparison voltages for the second stage.
    3. The final output code is composed as: MSBs * 2^N2 + LSBs.

    The comparison in each stage happens recursively (one comparator per bit), but for simplicity we compute the output code using the classic flash approach (comparing against all reference voltages simultaneously). Because there is only one closed switch per comparison, the RC time constant at the comparator input is approximately the same for all comparisons.

    Ncircuits = 100

uV = 1e-6
aF = 1e-18
fF = 1e-15

ru_err = 0.0
ru_std = 0.01

Num_comp_offsets = 1
comp_offsets = np.linspace(0, 1e-3, Num_comp_offsets)
adc_lins = []
avg_adc_lins = []

for comp_offset in comp_offsets:
    for _ in range(Ncircuits):
        # First stage resistor array
        ru = 1e3  # ohm
        res = np.ones(2**nbits_first) * ru
        r_err = normal(ru_err, ru_std, len(res))
        res = (1 + r_err) * res

        vcomps = np.array(
            [vref * (np.sum(res[0 : i + 1]) / np.sum(res)) for i in range(len(res) - 1)]
        )
        vcomps = comp_offset + vcomps

        ron = 100  # ohm
        ron_err = 0.0
        ron_std = 0.05
        r_err = normal(ron_err, ron_std, len(vcomps))
        rons = np.ones(len(vcomps)) * ron
        rons = (1 + r_err) * rons

        cg_comp = 20 * fF  # F
        cp = 1 * fF * len(rons) + cg_comp  # F
        taus = rons * cp  # s

        decoder_in_first = np.array([v &gt; vcomps for v in vin3])
        decoder_out_first = np.array(
            [np.count_nonzero(din) for din in decoder_in_first]
        )

        dout_first = decoder_out_first[np.where(np.diff(decoder_out_first) &gt; 0)]
        vtrans_first = vin3[np.where(np.diff(decoder_out_first) &gt; 0)]

        vlsb_measured_first = (vtrans_first[-1] - vtrans_first[0]) / (
            2**nbits_first - 2
        )
        dnl_first = np.diff(vtrans_first) / vlsb_measured_first - 1
        inl_first = np.array([0] + np.cumsum(dnl_first).tolist())

        # Second stage resistor array
        ru = 1e3  # ohm
        nbits = nbits_first + nbits_second
        res = np.ones(2**nbits) * ru
        r_err = normal(ru_err, ru_std, len(res))
        res = (1 + r_err) * res

        vcomps = np.array(
            [vref * (np.sum(res[0 : i + 1]) / np.sum(res)) for i in range(len(res) - 1)]
        )
        vcomps = comp_offset + vcomps

        lower_vcomp_idx = decoder_out_first * (2**nbits_second)
        upper_vcomp_idx = lower_vcomp_idx + 2**nbits_second - 1

        vcomps_second = np.array(
            [
                vcomps[lower_vcomp_idx[id] : upper_vcomp_idx[id]]
                for id in range(len(decoder_out_first))
            ]
        )

        decoder_in_second = np.array(
            [v &gt; vcomps_second[k, :] for k, v in enumerate(vin3)]
        )
        decoder_out_second = np.array(
            [np.count_nonzero(din) for din in decoder_in_second]
        )

        dout_second = decoder_out_second[np.where(np.diff(decoder_out_second) &gt; 0)]
        vtrans_second = vin3[np.where(np.diff(decoder_out_second) &gt; 0)]

        vlsb_measured_second = (vtrans_second[-1] - vtrans_second[0]) / (
            2**nbits_second - 2
        )
        dnl_second = np.diff(vtrans_second) / vlsb_measured_second - 1
        inl_second = np.array([0] + np.cumsum(dnl_second).tolist())

        decoder_out = decoder_out_first * 2**nbits_second + decoder_out_second

        dout = decoder_out[np.where(np.diff(decoder_out) &gt; 0)]
        vtrans = vin3[np.where(np.diff(decoder_out) &gt; 0)]

        vlsb_measured = (vtrans[-1] - vtrans[0]) / (2**nbits - 2)
        dnl = np.diff(vtrans) / vlsb_measured - 1
        inl = np.array([0] + np.cumsum(dnl).tolist())

        adc_linearity = nbits - np.log2(np.max(inl) - np.min(inl))
        adc_lins.append(adc_linearity)

    avg_adc_lins.append(np.mean(adc_lins))

    fig, ax = plt.subplots(1, 1, figsize=(4, 4))
ax.step(vtrans, dout, "k", label="output codes")
ax.set_xlabel("input voltage (V)")
ax.set_ylabel("output code")
ax.grid(True)
ax.set_title("Single Comparator 2-Step Sub-ranging Flash ADC Transfer Function")
